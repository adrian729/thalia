5. ~~**`useReverb.ts:82-100` (`setSelectedIR`) has an async race and no error handling.**~~ **DONE.** The fetch+decode of each IR is now cached at module scope (`Map<path, Promise<AudioBuffer>>`), since all instrument panels (2x `ThaliaPad` + `DrumPad`) share one `AudioContext` and mostly default to the same IR — this avoids each one independently re-fetching/re-decoding the identical file. Because that cache is shared, cancelling the underlying request (e.g. via `AbortController`) isn't an option — aborting would break every other consumer awaiting the same cached promise, not just the stale caller. Instead, each `useReverb` instance tracks the IR it most recently requested (`latestRequestedIRRef`) and discards a resolved call's result if that ref no longer matches — i.e. a newer selection on that same instance has already superseded it. The chain is `async`/`await` inside a `try`/`catch`, with `console.error` on real failures (a cache entry is evicted on rejection so a failed load doesn't permanently poison future attempts). Audible/functional behavior on the success path (gain values, timing, buffer assignment) is unchanged.
